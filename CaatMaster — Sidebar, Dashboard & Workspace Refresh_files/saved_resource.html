Refining the sidebar, dashboard, and workspace

CaatMaster already has a real design system — a Fluent-inspired palette and type scale in theme.py — and that's the right instinct for an audit tool people use alongside Excel and Office all day. This proposal doesn't replace it. It refines the three areas that have drifted from it: a sidebar whose action list has grown into an unsorted stack as features were added, a dashboard with some real layout bugs, and a data grid that's functional but visually flat. Nothing else changes — modals and dialogs are out of scope.

Nothing in the app has changed yet. Everything below is a mockup for review.

Sidebar

01 / 03
  • The core problem: ten sidebar features shipped this session all landed in one flat "Actions" list — it now reads as a junk drawer, not a menu.
  • Fix: group actions into four labeled clusters (Combine, Analyze, Import, Lineage & Export) with a subtle per-group icon tint for fast scanning.
  • Fix: Data / SQL Query become a segmented control — they're mutually exclusive modes, not list items competing with everything else.
  • Fix: the active dataset gets a real selected state (left rail + elevation), and row counts move into a quiet badge instead of crowding the label.

What's out of scope

Modals, dialogs, wizards, and the AI panel are untouched — you said they're fine, so this stays scoped to shell chrome.

What ships as real tokens

Every color/spacing value here maps directly onto theme.py's existing Colors/Spacing classes — this is a refinement of those tokens, not a parallel system.

Fonts

Inter, bundled as an app resource — already your fallback today, promoted to primary so the look is identical on Windows/Mac/Linux instead of depending on whichever system font is installed.
